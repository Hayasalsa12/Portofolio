Saya adalah seorang siswi SMK Telkom Purwokerto kelas X PPLG 5 jurusan RPL (Rekayasa Perangkat Lunak) yang memiliki ketertarikan mendalam dalam dunia teknologi, terutama di bidang desain UI/UX. Sejak kecil, saya sudah terbiasa berinteraksi dengan berbagai aplikasi dan perangkat lunak, dan saya mulai menyadari bahwa saya tertarik pada bagaimana desain sebuah aplikasi atau situs web bisa mempengaruhi pengalaman pengguna. Keinginan untuk menciptakan desain yang tidak hanya menarik secara visual, tetapi juga nyaman digunakan, mendorong saya untuk memilih jurusan RPL. Saya percaya bahwa pemahaman mendalam tentang rekayasa perangkat lunak akan memberi saya kemampuan untuk menciptakan antarmuka yang intuitif dan fungsional.

Selain itu, di SMK Telkom Purwokerto, saya mendapatkan banyak kesempatan untuk belajar dan mengembangkan keterampilan teknis, terutama dalam pengembangan perangkat lunak dan desain. Jurusan RPL yang saya pilih membuka banyak pintu untuk menggali lebih dalam tentang berbagai aspek teknologi, termasuk pemrograman dan desain antarmuka. Ketertarikan saya pada UI/UX semakin tumbuh, dan saya bersemangat untuk mempelajari lebih banyak teknik desain dan penggunaan alat-alat yang dapat membantu saya mewujudkan ide-ide kreatif. Saya berharap dapat mengembangkan keterampilan saya lebih lanjut, baik melalui proyek di sekolah maupun melalui pengalaman magang, sehingga bisa memberikan kontribusi pada perkembangan teknologi di masa depan.
