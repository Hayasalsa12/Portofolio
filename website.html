03 / CREATIVE FIELD

WEBSITE DEVELOPMENT.

Website development menjadi bidang yang membantu saya menggabungkan desain dengan teknologi. Melalui proses ini saya belajar bagaimana sebuah rancangan visual dapat dikembangkan menjadi halaman website yang dapat digunakan dan berinteraksi dengan pengguna.

INTRODUCTION

Building digital ideas.

Ketertarikan saya terhadap website development berkembang ketika saya mulai mencoba mengubah sebuah desain menjadi halaman website. Dari proses tersebut saya mulai memahami hubungan antara struktur HTML, tampilan CSS, dan interaksi menggunakan JavaScript.

Saya juga mulai mempelajari bagaimana sebuah website dapat disusun menjadi beberapa bagian, mulai dari navigation, hero section, content, gallery, hingga contact section sehingga keseluruhan halaman memiliki struktur yang jelas.

TUJUAN BELAJAR

Turn design into reality.

Tujuan saya mempelajari website development adalah memahami bagaimana sebuah konsep desain dapat diterapkan menjadi website yang benar-benar dapat digunakan.

Saya ingin meningkatkan kemampuan dalam HTML, CSS, JavaScript, dan teknologi web lainnya. Selain itu, saya juga ingin memahami bagaimana tampilan website dapat dibuat responsive sehingga tetap nyaman digunakan pada berbagai ukuran layar.

TARGET

Build, test, improve.

Target saya adalah mampu membuat website yang memiliki struktur kode yang rapi, tampilan yang konsisten, responsive, serta memiliki interaksi yang sesuai dengan kebutuhan pengguna.

Saya juga ingin terus meningkatkan kemampuan dalam menggabungkan hasil desain dari tahap perancangan dengan proses development sehingga hasil akhirnya tetap sesuai dengan konsep awal.

LEARNING PROCESS

From design to code.

Dalam proses belajar website development, saya mulai memahami bagaimana sebuah halaman website dibangun menggunakan HTML sebagai struktur utama. Setelah struktur dibuat, CSS digunakan untuk mengatur layout, ukuran, warna, typography, dan berbagai elemen visual lainnya.

Setelah memahami struktur dan tampilan, saya mempelajari JavaScript untuk memberikan interaksi pada website. Dengan JavaScript, beberapa bagian website dapat dibuat lebih dinamis sehingga pengguna dapat berinteraksi dengan halaman.

Proses membuat website juga mengajarkan saya pentingnya melakukan testing. Ketika sebuah bagian tidak berjalan sesuai rencana, saya perlu mencari penyebabnya, memperbaiki kode, kemudian mencoba kembali sampai mendapatkan hasil yang sesuai.

PROJECT EXPERIENCE

Learning through projects.

Salah satu cara saya mengembangkan kemampuan website adalah melalui project. Dengan mengerjakan project, saya dapat mempraktikkan materi yang dipelajari dan memahami bagaimana setiap bagian website saling berhubungan.

Melalui project tersebut saya belajar bahwa proses development tidak hanya tentang menulis kode, tetapi juga membutuhkan perencanaan, desain, testing, perbaikan, dan evaluasi terhadap hasil akhir.

REFLECTION

Keep building. Keep improving.

Website development membuat saya belajar untuk menggabungkan kreativitas dengan logika. Saya dapat menggunakan kemampuan desain untuk menentukan tampilan sekaligus menggunakan kemampuan coding untuk membuat tampilan tersebut menjadi sesuatu yang dapat digunakan.
